# trame-fespp-dock

The application's dock: the views of the layout today, a view's cards next.
One engine for both, so they share their gestures (tabs, drag and drop,
docking, detaching).

It starts as trame-dockview 2.0.1 (Kitware, MIT, see `LICENSE`), on the same
dockview 7.0.4, renamed (`FpDock`, `<fp-dock-view>`) so the two cannot
collide on a page, and grows what the application needs and the original does
not expose (a group's lock and header, floating groups).
